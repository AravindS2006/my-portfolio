01 / THE PROBLEM

Digital services should feel closer to home.

I built Periyakottai Digital Seva to help people in my village connect with a local e-Seva centre for digital assistance. The idea brings service information, document preparation and requests for help into one place.

A second part of the project is civic grievance reporting: giving residents a way to record issues such as water supply, streetlights and roads, with a ticket and progress history that can support follow-up.

The application is designed around Tamil-speaking residents, including people who may need larger text, voice support or help finding the right service.

02 / MY CONTRIBUTION

A local need shaped the product.

I brought a problem from my own village into a software project: making digital assistance easier to find and civic issues easier to report. I used AI coding tools to build the application around those needs.

The result brings together a resident-facing website and an operator interface, with bilingual content, service requests and grievance-management workflows. This is part of my work using agentic tools to turn practical needs into applications.

A grounded knowledge assistant

The assistant searches the project’s service, scheme and contact directories and formats a matching answer. It uses keyword and transliteration matching, with a fallback to the local operator. It is a directory-based assistant rather than an LLM or a generative AI model.

The application stack

Next.js, React, TypeScript and Tailwind CSS, with API routes for requests and grievances. The storage layer includes local JSON and optional Upstash/Redis REST persistence. These are technologies in the AI-assisted application, not a claim of independent expertise in each framework.

04 / LEARNING & SCOPE

Useful software starts with the people using it.

This project reflects my interest in applications that serve a concrete community need. Language, document preparation, understandable status updates and access to human help are central to that design.

Current scope: a community-focused application with the above workflows present in source. It is intended to help residents and local administration; official adoption, resolved-grievance totals and usage metrics have not been established. The repository is evidence of implementation, not an audit of production security or service outcomes.
