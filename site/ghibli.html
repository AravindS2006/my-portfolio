01 / THE CONTEXT

An approachable interface for an existing model.

The project explores stylized image generation through a web application. A text prompt is passed to hosted inference, and the generated result is presented through the interface.

02 / MY CONTRIBUTION

An application built with AI tools.

I used agentic coding tools to create this application. The agents generated the implementation, and the image models are third-party work. I did not train or fine-tune these models.

03 / WORK & EVIDENCE

What the implementation connects.

The generation route calls Hugging Face’s hosted FLUX.1-schnell model. An optional reference-image flow uses Gemma 3 for image descriptions, with fallback handling when that step is unavailable.

  • Text prompt to hosted image generation.
  • Optional reference-image description flow.
  • Next.js application code generated by AI coding tools.
Explore the source codeInspect the generation route

Current scope: API integration with experimental reference-image support. Hosted inference depends on the provider’s availability and credits. No affiliation with Studio Ghibli is implied.

04 / WHAT I LEARNED

A model is one part of an application.

This exploration brings together inputs, a hosted service and a user-facing result. A next step is to document generation failures, latency and reference-image behaviour using repeatable examples.
