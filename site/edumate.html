01 / THE PROBLEM

The dashboard was there. Mobile access wasn’t.

The original Edumate is the college ERP developed by Itech India Pvt. Ltd. for Sri Sairam Engineering College and Sri Sairam Institute of Technology. It covers student profiles, academic records, timetables, attendance, marks, documents, and job and internship management.

During a frontend modernization, the desktop experience became available while mobile access remained blocked during development. As a student, I saw the difficulty this created for classmates who needed to check their dashboard and attendance on a phone.

I built an independent mobile-first interface to the existing system. The college ERP and its data platform are the original developer’s work.

02 / MY CONTRIBUTION

I took the problem from inspection to deployment.

I inspected the existing website’s network behaviour with browser developer tools to understand its backend API and request-encryption format. I then used Google Antigravity to build a new mobile-first frontend and a compatible API layer.

My work involved identifying the access problem, investigating the integration, directing the AI-assisted build, deploying the application and changing the hosting setup as usage grew. The application code was generated with AI coding tools.

College students used the application. When traffic reached roughly 1,000 requests per day, I moved the backend from Vercel to Render while keeping the frontend on Vercel.

Usage and migration history are from my account of operating the project. Requests are not unique students; this figure is not a published analytics audit.

04 / LEARNING & SCOPE

Building was only the beginning.

This project gave me practical exposure to the development lifecycle: understanding API behaviour, connecting application layers, managing a GitHub-based development and deployment workflow, and revisiting hosting decisions after students started using the product.

It also introduced me to CI/CD concepts through GitHub and connected hosting. I’m continuing to develop the programming knowledge needed to understand, debug and maintain more of the implementation myself.

Project ownership: independent student-built interface; no claim of college or vendor endorsement. Next.js, React and TypeScript describe the application stack. My demonstrated contribution is the problem investigation, AI-assisted build and deployment work.
