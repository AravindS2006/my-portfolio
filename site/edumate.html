01 / THE CONTEXT

A familiar student workflow.

Attendance, schedules and academic information are things students return to repeatedly. Edumate explores bringing those views together in a mobile-first interface.

02 / MY CONTRIBUTION

Using agentic tools to build an idea.

I used Claude and Google Antigravity to create the application. The agents generated its full-stack code. This is an example of my exploration with AI coding tools; Next.js, React and TypeScript are application technologies, not skills I claim to know independently.

03 / WORK & EVIDENCE

Interface, API, information.

The repository contains a Next.js frontend and a Python FastAPI layer, with attendance, timetable and academic-information workflows. Its architecture provides a concrete project to inspect rather than just an idea to describe.

04 / WHAT I LEARNED

Keep the idea and authorship visible.

Agentic tools made it possible for me to explore a full application while continuing to develop my programming foundations. A useful next step is a reproducible demo using sample data, alongside documented checks of the core workflows.
