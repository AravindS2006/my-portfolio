# Aravindselvan C — Software Developer Portfolio

Modern, high-signal, and 100% legitimate personal portfolio website built with React 18, TypeScript, and Vite. Designed specifically for fresher software engineering and applied AI role recruitment.

## Professional Positioning
- **Headline**: Software Developer | Core Systems, Full-Stack & Applied AI
- **Flagship Proof-of-Work**:
  - **900+ Solved Challenges**: LeetCode (212+ solved) & SkillRack (691 solved, 223 bronze medals)
  - **$5,420 IEEE Project Grant**: AirTon handheld non-invasive medical screening prototype
  - **IMC Prosperity 4 Global Finalist**: Algorithmic trading and market-making strategies in Python
  - **Google Developer Program**: Diamond League member (7,264 points)

## Architecture & Features
- **Tiered Competencies**: Explicit, transparent skill matrix separating core programming, hardware/SDR telemetry, agentic full-stack delivery (orchestrating Claude Code / Google Antigravity), and foundational learning.
- **Interactive Project Showcase**: Filterable tabs across Hardware & IoT, Full-Stack, and Algorithmic systems with deep-dive architecture inspection modals.
- **Problem-Solving Metrics**: Dedicated dashboard showcasing verified statistics across LeetCode, SkillRack, Google Developer Program, and GitHub Pro.
- **Honors & Certifications**: Structured showcase of competitive honors, IEEE grants, HackerRank credentials, and NPTEL/AWS coursework.
- **Direct Contact & Resume**: Working PDF resume download, copy-to-clipboard email and phone, interactive message dispatch with graceful fallback.

## Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS with custom obsidian dark theme tokens (`#060813`)
- **Icons**: Lucide React
- **Email Service**: EmailJS Browser with native mailto fallback
