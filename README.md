# Aravindselvan C — Portfolio

Minimal and professional personal portfolio built with React + Vite.

## Highlights

- Clear recruiter-focused layout
- Professional summary, education, skills, internship, projects, achievements, certifications
- Direct links to LinkedIn, GitHub, and coding profiles
- Resume available at `/assets/Aravindselvan_C_Resume.pdf`

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS (CDN)

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
